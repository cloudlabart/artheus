# 아터스 비주얼 가이드 (사이트·이미지 공통)

## 인상
조용하고 단단한 연습실. 화려한 학원 광고가 아니라, 무대 뒤 리허설의 집중된 공기.
키워드: 편집 디자인(에디토리얼), 여백, 자연광, 종이 질감, 손글씨 메모가 붙은 대본.

## 색 (CLAUDE.md 디자인 규칙과 같음)
| 역할 | 색 |
|---|---|
| 배경 아이보리 | #F3F0EA |
| 카드 | #FAF8F4 |
| 딥블루(주색) | #153956 |
| 블루 | #2D5E88 |
| 라이트블루 | #A9C5D9 |
| 잉크(제목) | #132B3F |
| 본문 회청색 | #35526B |
새 색을 더하지 않는다. 강조는 딥블루 면, 라이트블루 선, 굵기 차이로.

## 레이아웃
- 넓은 여백, 큰 제목(한글 tracking -0.02em), 짧은 문단(keep-ko).
- 카드 rounded-2xl + 1px border-[#153956]/15, 버튼 rounded-full. 그림자는 거의 쓰지 않는다.
- 섹션마다 영문 eyebrow(작은 대문자, tracking 0.16em, #2D5E88) + 한글 제목.
- 모바일 390px 기준 먼저: 가로 스크롤 금지, 터치 영역 44px 이상, 글자 15px 이상.

## 이미지
- 사진풍: 자연광, 필름 그레인 약간, 아이보리·남색 톤. 리허설 룸, 블랙박스 무대, 대본, 의자, 창으로 드는 빛.
- 사람: 실루엣·뒷모습·손 위주. **실존 인물(강사·원생·배우) 얼굴을 생성하지 않는다.** 실제 강사 사진은 public/coaches/ 의 진짜 사진만 쓴다.
- 이미지 안에 글자·로고·워터마크 넣지 않는다(글자는 HTML로).
- 합격·성과를 연출하는 가짜 사진(합격증, 대학 로고, 시상식)은 만들지 않는다.
- 비율: 히어로 16:9(모바일은 4:5 대안), 카드 4:3, 인스타 4:5.
- alt는 한국어로, 무엇이 보이는지 한 문장.
- 키가 없거나 사진이 어울리지 않으면 SVG/CSS 그래픽(선, 무대 조명 원, 대본 줄 패턴)으로 대신한다.
