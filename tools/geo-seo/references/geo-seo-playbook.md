# GEO·SEO 플레이북 (한국어 · 네이버 + 구글 + AI 검색)

모든 스킬/에이전트가 공통으로 따르는 기준. 규칙 기반 검사는 `scripts/seo_lint.py`, 나머지는 LLM 검수.

## 0. 원칙 한 줄
**"질문에 첫 문장으로 답하고, 근거(수치·출처·경험)로 증명하고, 기계가 잘라 쓰기 좋게 구조화한다."**
SEO는 *순위*를, GEO는 *인용(Citation)*을 얻는 게임이다. 둘은 같은 글에서 동시에 달성한다.

---

## 1. 엔진별로 무엇을 보나

| 엔진 | 핵심 신호 | 글에 반영할 것 |
|---|---|---|
| 구글 검색 | 유용한 콘텐츠, E-E-A-T, 검색 의도 일치, 링크, 페이지 경험 | 의도별 H2, 1차 경험, 저자 정보, 구조화 데이터, 내부 링크 |
| 구글 AI Overview / AI Mode | 질의를 하위 질의로 쪼개(fan-out) 각 답을 여러 페이지에서 발췌 | 하위 질문마다 독립적으로 읽히는 40–80단어 답 블록, 표, 목록 |
| 네이버 통합검색 | C-Rank(출처·주제 전문성·꾸준함), D.I.A.+(문서 품질·경험 정보), 스마트블록(의도별 블록) | 한 주제 꾸준히 발행, 직접 경험·사진, 키워드를 제목 앞쪽에, 과도한 반복 금지 |
| 네이버 AI 브리핑(Cue: 후속) | 신뢰 출처 문서 요약 인용 | 요약 박스, 명확한 정의문, 출처 표기, 최신 날짜 |
| ChatGPT Search / Perplexity / Claude | Bing·자체 인덱스 기반 검색 후 인용. 명확성·권위·최신성·고유 데이터 | 독자적 수치/설문/사례, 엔티티 명확화, "2026년 기준" 표기, 인용하기 쉬운 문장 |

> 플랫폼 알고리즘 세부는 수시로 바뀐다. 작성 전 `content-brief` 단계에서 실제 SERP/AI 답변을 확인해 이 표를 보정한다.

## 2. GEO 작성 규칙 (AI 인용 최적화)

1. **Answer-first**: H1 바로 아래 `> **핵심 요약**` 인용 블록에 결론 3–5줄. 첫 문단은 질문에 대한 직접 답 2–3문장(40–300자).
2. **정의문**: 핵심 개념은 "○○란 ~를 말합니다." 형태로 한 문장에 정의. AI는 정의문을 그대로 발췌한다.
3. **자기완결 청크**: 각 H2 섹션 첫 1–2문장만 읽어도 답이 되도록. "위에서 말했듯이" 같은 앞 문맥 의존 표현 금지.
4. **질문형 소제목**: 실제 검색어/PAA/네이버 연관검색어를 소제목으로 ("~란?", "~하는 방법", "A와 B 차이").
5. **수치와 출처**: 섹션당 최소 1개 구체 수치. 모든 통계는 1차 출처 링크(정부·공공기관·논문·공식 문서·제조사). 출처 없는 숫자는 쓰지 않는다.
6. **고유 정보(Information Gain)**: 경쟁 글에 없는 것 1개 이상 — 자체 데이터, 실사용 경험, 사례, 체크리스트, 비교표, 비용 계산.
7. **표와 목록**: 비교·스펙·가격·단계는 반드시 표/번호 목록. 표 1개 이상, 목록 2개 이상.
8. **엔티티 명확화**: 브랜드·제품·기관·지역은 정식 명칭 + 첫 등장 시 짧은 설명. 대명사 남용 금지.
9. **최신성**: 제목 또는 도입부에 기준 연도, frontmatter에 `date`/`updated`. 갱신 시 updated만 바꾸지 말고 내용도 바꾼다.
10. **FAQ**: 3–6개, 각 답 1–3문장. 본문 하단 `## 자주 묻는 질문` + frontmatter `faq`(FAQPage 스키마 자동 생성).
11. **저자·신뢰**: author, author_bio(경력/자격), 검수자, 업데이트 이력. YMYL(건강·금융·법률)은 전문가 검수 필수 표기.

## 3. SEO 기본 규칙

- **제목**: 15–45자, 주 키워드를 앞쪽에, 숫자/연도/혜택 1개. 네이버·구글 공용으로 한 제목 사용 (필요 시 `seo_title` 분리).
- **메타 설명**: 70–160자, 키워드 포함, 답 + 클릭 이유.
- **슬러그**: 영문 소문자-하이픈, 60자 이하 (`naver-blog-seo-guide`).
- **헤딩**: H1 1개, H2 4개 이상, 계층 건너뛰기 금지.
- **키워드**: 도입부·H2 1개 이상·결론에 자연스럽게. 보조 키워드는 절반 이상 사용. 네이버는 본문 내 반복 3–12회 범위(과다 반복 = 어뷰징 판정 위험).
- **링크**: 외부 1차 출처 2개 이상, 내부 링크 2–3개(같은 클러스터 필러/형제 글).
- **이미지**: 설명형 alt 필수. 네이버는 직접 촬영 이미지 3–5장 이상이 경험 신호.
- **길이**: 의도에 맞게. 정보형 2,000–4,000자, 비교/가이드 3,000–6,000자. 길이를 위해 늘리지 않는다.
- **카니발리제이션**: 같은 의도 = 한 URL. 새 글 쓰기 전 GSC/사이트 검색으로 기존 글 확인.

## 4. 네이버 블로그 전용

- API 자동 발행 불가(글쓰기 API 종료) → `publish.py naver`가 붙여넣기용 파일 생성, 사람이 스마트에디터에 붙여넣고 사진 업로드.
- 외부 링크는 출처 목록으로 하단에 모으고 본문 중 과다 삽입 자제.
- 태그 5–10개, 띄어쓰기 없는 형태.
- 경험 서술(“직접 써보니”, 날짜·장소·비용)이 D.I.A.+ 신호. 브랜드 광고성 문구 과다 금지, 협찬은 표기.
- 블로그 주제 일관성(C-Rank): 계획 단계에서 블로그 주제 카테고리에서 벗어나는 키워드는 다른 채널로 배정.

## 5. 검색 의도 분류 (브리프에서 반드시 지정)

| 의도 | 신호어 | 형식 |
|---|---|---|
| 정보형 | 뜻, 이란, 원리, 방법 | 정의 → 원리 → 단계 → FAQ |
| 비교형 | vs, 차이, 비교, 추천, 순위 | 결론 먼저 → 비교표 → 상황별 추천 |
| 거래 전 | 가격, 비용, 후기, 할인 | 가격표(기준일) → 장단점 → 실제 후기 |
| 문제해결 | 안됨, 오류, 해결 | 원인 목록 → 해결 단계(HowTo) |
| 지역/업체 | 지역명+업종 | 위치·영업시간·가격·리뷰, LocalBusiness 스키마(사이트) |

## 6. 금지 사항

- 확인 안 된 수치, 가짜 후기, 경쟁사 비방, 의학·법률 단정.
- 키워드 나열식 문장, AI 티 나는 상투어("결론적으로 ~라고 할 수 있습니다", "다양한", "중요합니다"의 남발).
- 스키마에만 있고 본문에 없는 FAQ.
- 다른 글 문장 복제. 인용은 따옴표 + 출처.

## 7. 편집 원칙 (항상 적용 · config.editorial)

### 7-1. 청중을 구체화하고 청중에게 맞춰 쓴다
- 브리프 첫 줄에 **청중 한 문장**을 적는다: 누가(학년·전공·상황) / 언제 이 글을 찾나 / 읽고 나서 무엇을 할 수 있어야 하나.
  예) "실기 입시를 준비하는 고2–고3, 연극영화과 1–2학년. 대본을 받고 뭘 연기해야 할지 막막할 때 검색함. 읽고 나면 다음 연습에서 바로 써먹을 수 있어야 함."
- 글 안에서 청중이 실제 겪는 장면(입시 실기, 학교 공연, 오디션, 수업 과제)으로 예를 든다.
- 문체는 `editorial.voice`를 따른다. 독자에게 직접 말을 걸고, 한 문장에 한 가지만 말한다.
- 전문용어는 처음 나올 때 쉬운 말로 풀어 쓴다. 이론가 이름보다 "그래서 나는 뭘 하면 되나"가 먼저 나온다.

### 7-2. 솔루션은 손에 꼽을 수 있는 개수만
- 방법·단계·팁·실수 목록은 **각각 3–5개(최대 `editorial.max_solutions`)**. 6개 이상이면 묶거나 덜 중요한 것을 뺀다.
- 제목의 "N가지/N단계" 숫자도 같은 기준을 따른다.
- 핵심 요약은 3줄을 기본으로 한다. 독자가 글을 닫고 나서도 외울 수 있어야 한다.
- 표는 행을 5개 이하로 둔다.

### 7-3. 추천 도서는 항상 넣는다
- 본문 끝 `## 추천 도서` 섹션(참고 자료 앞)에 **2–3권**을 넣는다. 청중 수준에 맞는 책을 먼저 고른다(한국어판 우선, 없으면 원서로 표기).
- 각 책에는 다음을 적는다: 제목 · 저자 · 역자 · 출판사 · ISBN · **왜 이 독자에게 맞는지 한 줄** · **구매 링크**.
- 구매 링크: 국내서는 ISBN 검색 링크(알라딘·예스24·교보문고), 원서는 출판사 공식 페이지 + 알라딘 외서 링크.
  - 알라딘 `https://www.aladin.co.kr/search/wsearch.aspx?SearchTarget=Book&SearchWord=<ISBN>` (원서는 `SearchTarget=Foreign`)
  - 예스24 `https://www.yes24.com/Product/Search?query=<ISBN>`
  - 교보문고 `https://search.kyobobook.co.kr/search?keyword=<ISBN>`
- 서지 정보(역자, 출판사, ISBN, 한국어판이 있는지)는 웹 검색으로 확인한 것만 쓴다. 확인하지 못한 항목은 "확인되지 않음"으로 적는다.
- 제휴(어필리에이트) 링크는 쓰지 않는다(`editorial.affiliate_links: false`). 구매 링크는 일반 상품·검색 링크만 쓴다.
