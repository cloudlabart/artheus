# 아터스 스튜디오 · artheus 웹

> 학원 운영(CRM·상담·예약·수강료·카카오·인스타·유튜브)과 콘텐츠(홈페이지·칼럼·웹진·광고 영상)를 한 곳에서 하는 관리자 스튜디오입니다.
> `npm run dev` → http://localhost:5173/__studio (이 컴퓨터에서만 열림)

## 화면 구성 (브라우저형)
왼쪽 앱 목록에서 누르면 위쪽에 **탭**으로 열리고, `↗ 새 창`으로 떼어 낼 수 있습니다. 열어 둔 탭은 다음에도 그대로 열립니다.

| 앱 | 하는 일 |
|---|---|
| 홈 | 오늘 상담·네이버 예약·후속 연락·새 문의·미납·단계별 인원·AI 작업·SEO 한눈에 |
| CRM | 문의자·원생 연락처, 단계(문의→상담예약→상담완료→등록→수강중…) 목록·보드, 상담·수강료·메시지 이력, 동의 기록, CSV 가져오기·내보내기 |
| 상담 | 오늘·주간 달력·전체, 상담 결과에 따라 CRM 단계 자동 변경, 후속 연락일, AI 후속 메시지 초안 |
| 네이버 예약 | 예약 파트너센터 엑셀/CSV를 끌어다 놓으면 예약 현황으로(예약번호 기준 합치기), 상담 등록·CRM 연결 |
| 수강료 | 월 청구 일괄 생성(수강중 + 월 수강료), 납부 기록(계좌·카드·현금…), 미납·기한 경과, 6개월 수납 추이, CSV |
| 카카오 | 템플릿 + 받는 사람 묶음(내일·오늘 상담자, 미납자, 단계별, 직접) → 이름·날짜·금액 자동 채움 → 알림톡 발송(솔라피) 또는 복사, 보낸 기록 |
| 인스타 · 유튜브 | 팔로워·구독자, 게시물·영상별 반응, 유튜브 제목·설명 AI 제안 |
| 작업실 | 홈페이지 디자인(페이지)·칼럼 SEO·매니저 에이전트 (아래 설명) |
| 웹진 | 칼럼이나 주제 → AI가 7–9장 캐러셀 문구 → 1080×1350 카드 이미지(아이보리·딥블루·라이트블루), 사진 넣기, ZIP 받기, 캡션 복사 |
| 광고 영상 | 목적·타깃 → AI 장면별 대본 → 장면마다 사진·영상 → 9:16 세로 영상 MP4로 만들기, 촬영·내레이션 대본 복사 |
| 문체 | 배준우 문체 가이드 보기, 쌓인 첨삭, 분기 학습 → 초안 비교 → 적용, 분기 기록 |
| 설정 | 연동 키, 학원 정보(납부 기한), 백업 받기·복원, 개인정보 체크 |

**배준우 문체 (분기별 학습)**: 아터스 이름으로 나가는 모든 AI 글(웹진·광고·칼럼·상담 메시지·유튜브 설명·서버 월간 현행화)은 `content/style/voice.md`를 따릅니다. 스튜디오에서 일어나는 첨삭이 자동으로 모입니다 — 웹진·광고의 AI 문구를 고친 것, 칼럼을 직접 고친 문단, 칼럼·매니저에 준 수정 지시, AI 초안을 고쳐 보낸 카카오 메시지(문체 앱에서 직접 첨삭·글 추가도 가능). 분기가 바뀌면 홈에 알림이 뜨고, **문체 › 이번 분기 학습** → 초안(지금 가이드와 나란히 비교·수정) → **적용**하면 `voice.md`와 `content/style/history/<분기>.md`가 바뀝니다. 첨삭 원본은 `.studio/`에만 있고 GitHub에는 가이드만 올라갑니다.

**데이터와 개인정보**: CRM·상담·예약·수강료·메시지·웹진·광고와 연동 키는 이 컴퓨터의 `.studio/` 폴더에만 저장되고 GitHub(공개 저장소)에 올라가지 않습니다. 하루 한 번 `.studio/backup/`에 자동 백업(60일). 컴퓨터를 바꾸거나 고장에 대비해 설정 › 백업 파일 받기로 따로 보관하세요. AI 도우미에는 상담 메모만 보내고 연락처는 보내지 않습니다.

**연동 방법 요약** (설정 앱에 단계별 안내)
- 카카오: 채널 비즈니스 인증 → 솔라피 가입·채널 연동(pfId)·알림톡 템플릿 검수 → API Key·Secret·발신번호
- 네이버 스마트플레이스: 공개 API가 없어 예약 파트너센터 엑셀을 가져옴 (바로가기 주소만 저장)
- 유튜브: Google Cloud › YouTube Data API v3 키 + 채널 @핸들
- 인스타: 프로페셔널 계정 + 페이스북 페이지 → Meta 개발자 앱 장기 토큰(60일) + 비즈니스 계정 ID

## 동시 작업 · 매니저 (Admin)
- 요청 하나가 **작업** 하나가 되고, 여러 작업이 동시에 돕니다(기본 3개, `content/geo-seo.config.json › studio.max_jobs`). 왼쪽 **작업** 목록에서 진행 중인 작업을 눌러 오가며 봅니다. 끝나면 알림이 뜹니다.
- 같은 파일을 두 작업이 동시에 고치지 않도록 구역이 나뉩니다: 사이트 코드(페이지 탭)는 한 번에 하나, 칼럼은 칼럼마다 하나. 예) 칼럼 A 작성 + 칼럼 B 보강 + 홈 화면 수정을 동시에.
- 끝난 작업을 보고 있을 때 보내면 그 대화를 이어서, **새 대화**를 누르면 새 작업으로 시작합니다.
- **매니저 탭**: 큰 요청을 계획 → 서브에이전트에게 분배합니다. 서브에이전트(`.claude/agents/`): `seo-researcher`(리서치) · `content-writer`(원고) · `geo-reviewer`(검수) · `site-designer`(사이트 화면) · `seo-analyst`(SEO 분석). 서로 상관없는 일은 매니저 안에서 동시에 돌고, 진행이 서브에이전트별로 보입니다. 매니저는 무엇이든 고칠 수 있어서 도는 동안 다른 작업은 보낼 수 없습니다.
- 되돌리기는 그 작업이 맡은 구역만 되돌립니다(다른 작업의 결과는 그대로).

## 칼럼 탭
- **+ 새 칼럼**: 키워드(와 메모)를 넣으면 리서치 → 원고 → 검수 → 미리보기까지 진행합니다. 10–20분.
- **CSV / 주제 추천**: Search Console › 실적 › 내보내기 CSV를 올리면 실제 검색 데이터로 주제를 추천합니다.
- **칼럼 선택 → 채팅**: "도입부를 바꿔줘"처럼 말하면 그 칼럼을 고치고 미리보기를 다시 만듭니다.
- **미리보기**: 오른쪽 화면이 실제 발행될 `/column/<slug>/` 페이지입니다. 데스크톱·모바일 버튼으로 확인합니다.
- **네이버용 열기**: 네이버 블로그에 붙여넣을 제목·본문·태그 복사 페이지.
- **발행**: 검수 통과 · 채울 자리 없음 · 저자 있음일 때만 됩니다. `public/column/`·사이트맵·RSS를 만들고 GitHub에 올리면 GitHub Pages가 배포합니다.
- 칼럼 작업에는 Python 3이 필요합니다(Mac은 기본 설치. `python3 --version`으로 확인).

## 서버 정기 SEO (GitHub Actions)
스튜디오를 켜지 않아도 GitHub에서 자동으로 돌아갑니다. 결과는 저장소의 **Issues › SEO 주간 리포트**에 쌓이고, 스튜디오 칼럼 탭의 **SEO 현황**(최신 받기 후)에도 보입니다.

| 작업 | 언제 | 하는 일 | 사이트 반영 |
|---|---|---|---|
| SEO 주간 점검 (`.github/workflows/seo-weekly.yml`) | 매주 월 09:17 | Search Console 최근 28일 vs 이전 28일, 칼럼별 순위·클릭 변화, 본문에 없는 검색어, 오래된 내용(120일), 지난 연도 제목, 깨진 링크, 사이트맵·canonical 점검, 새 주제 후보 → `content/reports/` | 사이트맵·칼럼 페이지 재생성만 |
| 칼럼 현행화 (`.github/workflows/seo-refresh.yml`) | 매월 1일 10:37 | 점검의 "보강 필요" 상위 2편을 Claude가 보강 → **PR** 생성 | PR을 병합해야 반영 |

**처음 한 번 설정 (GitHub 저장소 › Settings › Secrets and variables › Actions › New repository secret)**
1. 칼럼 현행화용 Claude 열쇠 (둘 중 하나):
   - `CLAUDE_CODE_OAUTH_TOKEN` — Claude Pro/Max 구독으로 쓰기. Mac 터미널에서 `claude setup-token` → 브라우저 승인 → 나온 토큰을 넣기(구독 사용량에서 차감, 추가 결제 없음).
   - `ANTHROPIC_API_KEY` — https://console.anthropic.com 에서 발급(쓴 만큼 별도 과금).
2. `GSC_SA_KEY` (선택이지만 권장) — 검색 성과 점검용.
   - Google Cloud 콘솔에서 프로젝트 생성 → **Google Search Console API** 사용 설정 → 서비스 계정 만들기 → 키(JSON) 생성.
   - Search Console › 설정 › 사용자 및 권한 › 사용자 추가 → 서비스 계정 이메일을 **제한됨** 권한으로 추가.
   - 키 JSON 내용을 통째로 Secret 값에 붙여넣기.
3. Actions 탭 › **SEO 주간 점검** › Run workflow 로 한 번 실행해 확인.

설정값(`content/geo-seo.config.json › maintenance`): `refresh_after_days`(오래됨 기준 일수), `auto_refresh_per_month`(월 자동 보강 편수), `min_impressions`.
리포트만 바뀐 커밋은 다시 배포하지 않습니다.
**공개 저장소라서** 서버 리포트(이슈·`content/reports/`)에는 클릭·노출·순위 숫자를 싣지 않고 "할 일"만 남깁니다. Search Console CSV(`content/data/`)는 git에 올라가지 않습니다. 숫자가 들어간 점검은 Mac 스튜디오 › 칼럼 › CSV 올리기 → SEO 점검으로 봅니다(`.studio/reports/`, 이 Mac에만 저장).

## 배포 (GitHub Pages)
`main`에 올라오면 **Actions › 사이트 배포**가 칼럼 페이지 생성 → 빌드 → GitHub Pages 배포까지 합니다.

처음 한 번 설정:
1. 저장소 **Settings › Pages › Build and deployment › Source** 를 **GitHub Actions** 로.
2. 도메인 회사(가비아 등) DNS에 미리보기 주소 추가: `new` CNAME `cloudlabart.github.io` (지금 c-art.co.kr 사이트에는 영향 없음).
3. **Settings › Pages › Custom domain** 에 `new.c-art.co.kr` 입력 → Enforce HTTPS 체크.
4. **Settings › Secrets and variables › Actions › Variables** 에 `PAGES_DOMAIN` = `new.c-art.co.kr`.
5. **Actions › 사이트 배포 › Run workflow**.

미리보기 기간에는 모든 페이지가 검색 제외(noindex)입니다. 개편이 끝나 도메인을 옮길 때:
- DNS: `@` A 레코드 4개 `185.199.108.153` `185.199.109.153` `185.199.110.153` `185.199.111.153`, `www` CNAME `cloudlabart.github.io` (MX·TXT 메일 레코드는 건드리지 않기)
- Custom domain 을 `www.c-art.co.kr` 로, 변수 `PAGES_DOMAIN`=`www.c-art.co.kr`, `SEARCH_INDEXING`=`on` → 사이트 배포 다시 실행

# artheus 웹 (Figma 독립 버전)

Figma Make "아터스" 프로젝트에서 뼈대만 가져와, Figma 없이 어디서나 실행·배포할 수 있게 만든 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 배포는 GitHub Pages(위 "배포" 참고)로 자동으로 됩니다.

## 들어 있는 것 (원본 그대로)

| 영역 | 파일 |
|---|---|
| 홈 화면 전체 (히어로, 수업 방식, 강사·수강료, artheus ON 배너, 합격 대학 로고, 상담) | `src/app/pages/Home.tsx` |
| 상단 메뉴 · 모바일 메뉴 | `src/app/components/Header.tsx` |
| 푸터 · 오른쪽 빠른 상담 메뉴 · 커서 빛 효과 | `Footer.tsx`, `QuickMenu.tsx`, `CursorGlow.tsx` |
| 인스타그램 상담 버튼 (GTM 클릭 기록 포함) | `InstagramConsultButton.tsx` |
| 디자인 토큰 · 글꼴 · 공통 스타일 | `src/styles/` |
| 대학 로고 11개 | `src/assets/` |
| Google Tag Manager (GTM-N6Z4Q7MX), 파비콘, SNS 공유 이미지 | `index.html`, `public/` |

Figma가 배포할 때만 넣어 주던 GTM·파비콘·공유 이미지를 `index.html`과 `public/`에 직접 넣었습니다.

## 자리표시로 둔 것

- **공개 페이지:** 비전, 코치, 프로그램, LAB, 컬럼, Zine, 공지, 문의 등은 메뉴는 동작하지만 화면은 자리표시입니다. 이름표는 `src/app/App.tsx`의 `PAGES` 표에 있습니다.
- **로그인 이후 화면:** 로그인, 회원가입, 마이페이지, 관리자, 강사 콘솔, artheus ON도 자리표시입니다.
- **로그인 상태와 데이터:** `contexts/AuthContext.tsx`는 항상 로그아웃 상태, `DataContext.tsx`는 빈 목록입니다.

원본의 해당 페이지가 필요하면 Figma Make에서 그 파일만 다시 가져올 수 있습니다.

## Supabase

`utils/supabase/info.tsx`에 기존 Supabase 프로젝트 연결 정보가 그대로 있습니다. 홈의 강사 사진과 푸터 연락처는 기존 서버에서 불러오고, 실패하면 기본값으로 표시됩니다.

## 원본과 달라진 점

- `package.json`: Figma 전용 설정(`vite.figma.config.ts`)을 쓰지 않고, 실제로 쓰는 패키지만 남겼습니다.
- `App.tsx`: 자리표시 페이지로 연결하도록 단순화했습니다. 원본의 신규 강사 팝업은 빠졌습니다.
- `docs-original/`: 원본 문서를 참고용으로 보관했습니다.

## 바이브 코딩 스튜디오 (artheus Studio)

`npm run dev`를 켜고 **http://localhost:5173/__studio** 를 열면, 왼쪽 채팅창에 말로 요청하고 오른쪽 미리보기 모니터에서 바로 결과를 보는 화면이 나옵니다.

- **요소 선택**: 미리보기에서 고칠 부분을 클릭하면, 그 요소를 만드는 코드 위치(예: `src/app/pages/Home.tsx:205`)를 찾아 Claude에게 함께 전달합니다.
- **실시간 반영**: Claude가 파일을 저장하는 즉시 미리보기가 바뀝니다. 새로고침이 필요 없습니다.
- **되돌리기**: 요청할 때마다 직전 상태를 `.studio/snapshots/`에 저장합니다. 화면 아래 ‘되돌리기 기록’에서 원하는 시점으로 돌아갈 수 있습니다(최근 30개).
- **이미지 첨부**: ‘이미지’ 버튼, 붙여넣기(⌘V), 끌어다 놓기로 한 번에 8장까지 첨부합니다. 참고 캡처(“이 화면처럼 만들어줘”)로도, 사이트에 넣을 사진(“이 사진을 강사 소개에 넣어줘”)으로도 쓸 수 있습니다. 첨부한 이미지는 `public/uploads/`에 저장되고, 사이트에서는 `/uploads/파일이름` 주소로 쓰입니다.
- **기기 크기**: 데스크톱 1440 · 태블릿 820 · 모바일 390 화면으로 바꿔 볼 수 있습니다.
- **대화 이어가기**: 같은 대화 안에서는 앞선 요청을 기억합니다. ‘새 대화’로 초기화합니다.

### 준비물
이 컴퓨터에 **Claude Code**가 설치되어 있고 로그인되어 있어야 합니다. 별도의 API 키는 필요 없고, 본인 Claude 계정 사용량으로 동작합니다.

```bash
npm install -g @anthropic-ai/claude-code
claude
```
처음 한 번 `claude`를 실행해 로그인하면 됩니다.

### 안전장치
- Claude는 파일 읽기·검색·수정만 할 수 있습니다. 명령 실행(설치, 삭제, git 등)은 막혀 있습니다.
- `studio/` 폴더는 고치지 않도록 지시되어 있습니다.
- 스튜디오는 이 컴퓨터(localhost)에서 열 때만 동작합니다. 같은 와이파이의 다른 기기에서 접근하면 거부합니다.
- 개발 서버 전용입니다. `npm run build`로 만드는 배포 파일에는 스튜디오가 들어가지 않습니다.
