# 화면 검토·다듬기

## 1. 보기
```
node tools/studio/shot.mjs <경로> 1440,390
```
출력된 png를 **Read로 열어 직접 본다.** 가로 넘침·화면 오류가 출력되면 그것부터 적는다.
코드도 함께 읽는다(해당 페이지·컴포넌트).

## 2. 기준 (순서대로)
1. **목적·위계**: 3초 안에 무엇을 하는 화면인지, 상담 버튼(InstagramConsultButton)이 보이는지
2. **모바일 390px**: 가로 스크롤, 글자 15px 이상, 터치 영역 44px 이상, 줄바꿈(keep-ko)
3. **브랜드 일관성**: CLAUDE.md 색 토큰만 쓰는지, rounded-2xl·rounded-full·1px 테두리, 임의의 그림자·그라데이션
4. **간격·정렬**: 섹션 간격 리듬, 왼쪽 정렬선, 카드 높이
5. **문구**: voice.md 톤, 버튼 문구가 행동을 말하는지, 영어 남용
6. **접근성**: 대비(본문 4.5:1), 이미지 alt, 버튼에 이름, 포커스 표시, 제목 순서(h1→h2)
7. **상태**: 빈 목록·불러오는 중·오류 화면
8. **템플릿 느낌**: 흔한 AI 사이트처럼 보이는 요소(보라 그라데이션, 이모지 남발, 똑같은 카드 3개)

## 3. 결과 형식
```
## 먼저 고칠 것
1. [모바일] 무엇이 · 어디서(파일:줄) · 어떻게
…(최대 7개, 중요한 순서)
## 괜찮은 점
한두 줄
```
"검토만" 요청이면 여기서 끝낸다(파일을 고치지 않는다).

## 4. 다듬기 요청이면
위 목록의 1–5번을 고친 뒤 다시 캡처해 Read로 확인하고, 전후 차이를 한 줄씩 적는다.
