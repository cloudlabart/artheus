# 화면 문구

1. `content/style/voice.md`를 먼저 읽는다. 가이드와 충돌하면 가이드가 이긴다.
2. 대상 화면 코드와 `src/content/site.json`을 읽는다. 사실(수치·합격 실적·가격)은 있는 것만 쓰고 지어내지 않는다. 없으면 "확인 필요"로 남긴다.
3. 원칙
   - 제목은 짧게, 무엇을 얻는지. 버튼은 행동(“상담 신청하기”, “프로그램 보기”).
   - 한 문단 2–3문장. 한글 문단에는 keep-ko.
   - 과장·최상급(“최고”, “100%”) 금지. 합격 보장 표현 금지.
   - 영어 eyebrow는 유지하되 본문은 한국어.
4. 바꾼 문구는 "전 → 후" 목록으로 답한다.
